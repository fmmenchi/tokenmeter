# What's new

After an update that brings new features, a card at the top of the panel says how many and opens their list.

|        |                                  |
| :----- | :------------------------------- |
| Date   | 2026-11-16                       |
| Status | plan written, waiting for review |

## Intent

The notes of a version are shown before it is installed, and only for that version. A person who skips releases never sees what
changed, and nothing in the app says that something new is there. The card says it once, with the features only: the fixes stay in the
changelog.
