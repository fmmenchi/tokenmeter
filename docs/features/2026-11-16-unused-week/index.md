# Unused week

In the last two days of a week that still has half its quota or more, the panel says so on the Weekly bar, and a notice can tell it.

|        |                                    |
| :----- | :--------------------------------- |
| Date   | 2026-11-16                         |
| Status | implemented, 2026-11-16, in 0.15.0 |

## Intent

The notices said when a quota runs out, never when it goes to waste. A plan paid by the month loses the part of a week that is not
used before the reset. Two days before it, there is still time to use it.
