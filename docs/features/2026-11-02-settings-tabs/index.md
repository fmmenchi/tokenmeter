# Settings in tabs

The Settings window shows one section at a time, chosen from a row of tabs, instead of one long column.

|        |            |
| :----- | :--------- |
| Date   | 2026-11-02 |
| Status | in build   |

## Intent

Settings grew with each feature: launch at login, the providers and their windows, notifications, updates and now the skins. With
the skins it was far too long for a window that does not scroll, and a person looking for one switch had to read past all of the
others. Five tabs keep each section within one screen and put the one the person wants a click away.

Nothing about what a setting does changes: only where it sits.
