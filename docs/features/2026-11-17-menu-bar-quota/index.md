# Quota in the menu bar

Beside the gauge, one figure per provider, in the order of the panel's cards; a hover names them.

|        |                   |
| :----- | :---------------- |
| Date   | 2026-11-17        |
| Status | in design, chosen |

## Intent

The bar shows the gauge only, so knowing how much is left means opening the panel. A figure per provider says it at a glance,
and the order of the panel, which the user sets, says which provider each figure is: no logo is needed. It answers the reason
the bar lost its figure in [Menu bar: icon only](../2026-11-02-menu-bar-icon-only/index.md), a single percentage across
several providers that did not say which plan it was about.
