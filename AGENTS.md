# AGENTS.md

Operating contract for this repository.

## Project

`tokenmeter` — a macOS widget and menu-bar item that monitors the remaining quota of Claude and
ChatGPT plans. Stack: SwiftUI, WidgetKit, `MenuBarExtra` ([ADR 0001](./docs/adr/0001-app-architecture.md)).
Metric and sources: [ADR 0002](./docs/adr/0002-quota-model-and-data-sources.md).

Gate: `pnpm run check`. Spike: `swift run tokenmeter-probe`.

## Open decisions

- **Claude remaining quota** — comes from the status line (ADR 0002); stale until a session runs.
- **Updates** — Sparkle ([ADR 0011](./docs/adr/0011-updates.md)), in use since v0.3.0 (2026-11-02, the first version that can update itself). The author saw it on his Mac: v0.3.0 found v0.4.0 from the feed of the latest release, showed its notes page readable in the dark appearance, and updated to it. The public half of the signing key is in `project.yml`; a backup of the private half was made by the author in a password manager (not verified by the agent). Still unverified: the widget refreshing after a real update, the stats staying as they were after one, a download with Gatekeeper's quarantine, and the double click on another Mac.
- **Notifications** — released in v0.4.0 (2026-11-02), built ([ADR 0012](./docs/adr/0012-limit-notices.md)), the rule is tested in the core; unverified are the permission prompt, a notice on a real Mac, a click on it, Focus modes and the page the button opens in System Settings.
- **Developer menu** — a hammer button in the panel of a debug build only (`#if DEBUG`, `App/TokenMeter/EasterEggs/DevMenu.swift`) forces the event of the easter eggs, an exception to the no-mock-modes rule asked for by the author; it is absent from a release.
- **Seasonal easter eggs** — released in v0.5.0 (2026-11-02), icons and tick fixed in v0.5.1 ([plan](./docs/features/2026-11-02-seasonal-easter-eggs/plan.md)), not yet seen in the app, because they only show in the week of an event and there is no mock mode: the weeks are tested in the core and the drawing was checked on the real views offscreen; the images are generated by the author with an AI image tool (their licence status is not verified).
- **Skins** — five looks ([ADR 0013](./docs/adr/0013-skins.md), [plan](./docs/features/2026-11-02-skins/plan.md)): System, Dracula, One Dark, Catppuccin, Nord, from MIT-licensed editor themes (notices in `Licenses/Skins-LICENSES.txt`). Released in v0.6.0 (2026-11-02); the solid panel over the real window material and the widget in each size are unverified, and Dracula's light version is derived, not official.
- **Welcome wizard** — merged into `main` on 2026-11-03, not released yet ([plan](./docs/features/2026-11-03-welcome-tour/plan.md), no ADR): a window of seven pages that opens once, on a new install and on the first update. Seen on the author's Mac only in the dark appearance and by opening each page from a debug build; unverified: the light appearance, the first update with a real one and a small display. The pictures of the panel and the stats are the app's own views drawn with invented sample data, light and dark.
- **Notarized release** — v0.7.0 is published, signed and notarized (ADR 0008); the widget was verified on the author's Mac with the Developer ID build of v0.2.0, and the double click on another Mac is unverified.

## How we work

- **A structural decision gets an ADR first**, and is not made until it is written.
- **A feature is a nucleus** of proposal, implementation plan and ADRs in `docs/features/`, built in that order ([features](./.agents/doc/features.md)). The `feature` skill runs the flow and stops at each approval.
- **Never work on `main`.** Every feature or fix is built on its own semantic branch, with conventional commits.
- **Never bypass a hook.**
- **Never push.** Fabio pushes. A finished branch is merged into `main` with a **merge commit** (`git merge --no-ff`), never
  a fast-forward and never a rebase onto `main`.
- **`AGENTS.md` only.** Never add a `CLAUDE.md`.
