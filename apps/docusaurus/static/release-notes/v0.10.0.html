tokenmeter 0.10.0

Released on 2026-11-04.

  • Accounts: a work account and a personal one, each with its own card. An account is a folder Claude Code or the Codex CLI reads, named by a home in its entry of providers.json; the status line is set up and /usage asked in each account's own folder, the problems name the account, and a folder nobody named is found at the top of the home and offered in the panel with Add it (Accounts).
  • Settings has an Accounts tab in place of Providers: add, rename or remove an account, each through a sheet, with the email the folder is signed in with under its name (Settings).
  • The order and the visibility of the cards moved to the panel, behind a lock: open it and the cards get arrows, an eye each and one on each window, and drag onto one another; a hidden card stays in sight, dimmed, until the lock closes.
  • The welcome has eight pages: the seventh says what an account is (The welcome).
